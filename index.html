Research

Parallel Non-Integer Multiple-Cell-Height Node Remapping

Developed a path-parallel dynamic programming framework for non-integer multiple-cell-height circuit optimization, targeting improved runtime, timing, and placement quality.

ML/GPU-Enhanced Mixed-Size Placement

Investigated cell-wise adaptive density weighting for analytical mixed-size placement using machine learning models and GPU-accelerated optimization.
